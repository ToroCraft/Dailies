# Bailey's Dailies

A Minecraft mod that adds a daily quest system to your world. Complete quests given by Bailey NPCs in villages to earn rewards and experience.

## What is Bailey's Dailies?

Bailey's Dailies transforms Minecraft villages by adding Bailey NPCs who offer daily quests. These friendly traders provide various challenges including collection, crafting, exploration, and achievement-based quests. Complete quests to earn experience points, items, and unlock new content.

## Technical Requirements

- **Minecraft**: 1.21.4
- **Mod Loader**: NeoForge 21.4.152+
- **Java**: 21+

## Online & Offline Modes

- **Online Mode**: Integrates with [minecraftdailies.com](https://minecraftdailies.com) for enhanced quest tracking and community features
- **Offline Mode**: Fully functional standalone mode - no internet connection required

## Key Features

- Daily quest system with Bailey NPCs in villages
- Multiple quest types: collection, crafting, exploration, achievements
- Automatic Bailey shop generation in villages
- Configurable quest settings and spawn rates
- Works in single-player and multiplayer
- Complete offline functionality

## Installation

1. Install NeoForge 21.4.152+ for Minecraft 1.21.4
2. Download the latest release from [Releases](../../releases)
3. Place the `.jar` file in your `mods` folder
4. Launch Minecraft

## Commands

- `/dailies spawn_bailey_shop` - Manually spawn a Bailey shop near you (requires OP)
